Aplicación web desarrollada con React y Vite para gestionar proyectos educativos.

Permite:
- Agregar proyectos
- Buscar proyectos
- Eliminar proyectos
- Visualizar categoría y estado
- Gestionar proyectos mediante una interfaz dinámica y responsive
